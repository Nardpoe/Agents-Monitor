# Changelog

All notable changes to Agents Monitor will be documented in this file.

The project follows semantic versioning where practical.

## [0.1.0] - 2026-09-23

### Added

- Initial public release
- Local Codex session monitoring
- Local Claude Code session monitoring
- Codex rate-limit display when available in local session data
- Burn-rate and token-per-minute metrics
- Compact and expanded dashboard modes
- Windows browser window docking and always-on-top helpers
- Local-only server bound to `127.0.0.1`
- Automated tests and GitHub Actions CI
- MIT license and contribution guidelines
