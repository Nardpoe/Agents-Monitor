# Code of Conduct

## Our Standard

Agents Monitor aims to be a welcoming, practical, and respectful open-source community.

Good participation includes:

- treating other contributors with respect
- discussing ideas and code without attacking people
- giving constructive feedback
- respecting different experience levels and backgrounds
- protecting private information shared accidentally
- keeping technical discussions relevant and useful

Unacceptable behavior includes harassment, threats, discrimination, deliberate exposure of private information, repeated personal attacks, or disruptive behavior intended to make collaboration difficult.

## Enforcement

If you experience or observe unacceptable behavior, contact the repository maintainer through GitHub. Reports should be handled as privately as the available communication channel allows.

Maintainers may edit or remove comments, reject contributions, lock discussions, or restrict participation when necessary to protect the community.

## Scope

This code of conduct applies to project spaces such as issues, pull requests, discussions, and other public interactions directly related to Agents Monitor.
