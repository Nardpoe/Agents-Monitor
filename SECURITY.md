# Security Policy

Agents Monitor reads local session metadata, so privacy and safe handling of local data are important.

## Reporting a Vulnerability

Please do not publish sensitive exploit details, credentials, private logs, prompt content, or personal file paths in a public issue.

For a sensitive security or privacy problem:

1. Create a minimal GitHub issue stating that you found a security or privacy concern.
2. Do not include secrets or exploit details in the public issue.
3. Ask the maintainer for a private communication channel before sharing sensitive details.

For non-sensitive bugs, use the normal bug report template.

## Supported Version

The project is currently in early development. Security fixes are expected to target the latest version on the `main` branch.

## Local Data

When sharing logs or screenshots, remove:

- prompt text
- task names
- usernames and personal paths
- API keys and tokens
- private repository names
- any other identifying or confidential information
